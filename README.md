# Instapro — социальная сеть SkyPro

Это клиентская часть приложения, написанная на чистом JavaScript.  
Приложение позволяет:
- Регистрироваться и авторизоваться
- Просматривать ленту постов
- Ставить лайки и дизлайки
- Добавлять собственные посты с описанием и изображением
- Удалять свои посты с подтверждением (всплывающее окно)

---

## Реализованная функциональность

✅ **Авторизация и регистрация**  
✅ **Лента постов (общая и пользовательская)**
✅ **Добавление постов с изображением**
✅ **Лайки/дизлайки с анимацией**
✅ **Удаление постов с подтверждением через `confirm()`**
✅ **Адаптивный интерфейс**

---

## Затраченное время

🕒 **Первоначальная оценка:** 8 часов  
🕒 **Фактически затрачено:** ~12 часов

> Причины перерасхода:
- Долгий разбор ошибок API
- Проблемы с импортом `date-fns`
- Отладка запросов к серверу
- Добавление анимаций и улучшений UX

---

## 💡 Дополнительные фичи

- Анимация лайка при наведении и клике (`@keyframes`, `transition`)
- Подтверждение удаления поста через модалку браузера (`confirm(...)`)
- Переход к постам пользователя по клику на имя
- Отображение даты создания поста (упрощённый формат: `03.05.2025 14:30:00`)
- Обновление лайков без перезагрузки страницы

---

## 🔧 Технические детали

- API: https://wedev-api.sky.pro 
- Авторизация: Bearer токен
- Формат данных: JSON
- Загрузка изображений: `FormData`
- Клиентская маршрутизация: реализована вручную через `goToPage(...)` и `renderApp()`

---

## 🛠 Как запустить проект:

1. Клонируйте репозиторий
2. Установите Live Server или любой локальный сервер
3. Запустите командой `npm run start` или откройте `index.html` через Live Server
4. Перейдите на главную страницу → всё работает!
