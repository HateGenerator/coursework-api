# Instapro — социальная сеть SkyPro

Это клиентская часть приложения, написанная на чистом JavaScript.  
Приложение позволяет:
- Регистрироваться и авторизовываться
- Просматривать ленту постов (общая и пользовательские)
- Ставить и убирать лайки
- Добавлять собственные посты с описанием и изображением
- Удалять свои посты с подтверждением через всплывающее окно

---

✅ **Авторизация и регистрация**  
✅ **Лента постов (общая и пользовательская)**

## 🔧 Технические детали

- **API:** https://wedev-api.sky.pro   
- **Авторизация:** Bearer токен
- **Формат данных:** JSON
- **Загрузка изображений:** через `FormData`
- **Клиентская маршрутизация:** реализована вручную через `goToPage(...)` и `renderApp()`

## 🛠 Как запустить проект:

1. Клонируйте репозиторий
2. Откройте `index.html` через Live Server или любой локальный сервер
3. Перейдите на главную страницу → всё работает!
